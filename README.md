# Certificación en C# .NET – Nivel 2 (Maxi Programa)

Este repositorio contiene ejercicios, ejemplos y proyectos desarrollados durante el curso **Nivel 2 de C# .NET**, orientado a la creación de aplicaciones profesionales con integración de bases de datos y buenas prácticas de programación.

## 📌 Contenidos del curso
- **Repaso de fundamentos**: conceptos clave de C# vistos en Nivel 1.
- **POO (Programación Orientada a Objetos)**: clases, objetos, encapsulamiento, herencia y polimorfismo.
- **POO avanzado (POO++)**: interfaces, abstracción y colecciones genéricas.
- **WinForms**: creación de interfaces gráficas en Windows, manejo de eventos y controles.
- **SQL y GitHub**: fundamentos de bases de datos relacionales, consultas SQL y control de versiones con GitHub.
- **Conexiones DB**: integración de C# con SQL Server, consultas y manipulación de datos desde aplicaciones.
- **Arquitectura en capas**: separación en presentación, lógica de negocio y acceso a datos.
- **Proyecto integrador**: aplicación completa que combina POO, WinForms y SQL.

## 🎯 Objetivos
- Modelar sistemas con **POO** y aplicar buenas prácticas de programación.
- Desarrollar aplicaciones gráficas con **WinForms**.
- Integrar bases de datos SQL en proyectos C#.
- Implementar **arquitectura en capas** para proyectos escalables.
- Usar **GitHub** para versionado y documentación de proyectos.

## 🚀 Tecnologías utilizadas
- **C# .NET**
- **SQL Server**
- **WinForms**
- **GitHub / Git**
